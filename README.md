## ✨ Sobre o projeto

O **Clara Mendes Fotografia** é um website desenvolvido para apresentar o trabalho de uma fotógrafa profissional de maneira elegante, moderna e intuitiva.

O projeto possui uma identidade visual minimalista, utilizando tons neutros, tipografia sofisticada e fotografias em destaque para transmitir personalidade e profissionalismo.

A proposta é criar uma presença digital que permita aos visitantes conhecer o trabalho da fotógrafa, explorar suas galerias e solicitar orçamentos de maneira simples.

## 🚀 Funcionalidades

- **Apresentação profissional:** seção dedicada à história e apresentação da fotógrafa.
- **Galeria de fotografias:** exposição de trabalhos organizados por categorias.
- **Filtros dinâmicos:** navegação entre retratos, casamentos, família e eventos.
- **Visualização ampliada:** abertura das fotografias em uma janela modal.
- **Serviços:** apresentação das modalidades de fotografia oferecidas.
- **Formulário de orçamento:** coleta de informações para solicitações comerciais.
- **Integração com WhatsApp:** encaminhamento automático das solicitações para uma conversa.
- **Design responsivo:** adaptação para computadores, tablets e smartphones.

## ⚙️ Como executar o projeto

**1. Clone o repositório**

```bash
git clone URL_DO_REPOSITORIO
```

**2. Acesse a pasta**

```bash
cd portfolio-fotografo
```

**3. Abra no Visual Studio Code**

```bash
code .
```

**4. Execute o projeto**

Abra o arquivo `index.html` utilizando a extensão Live Server ou diretamente pelo navegador.

Não é necessário instalar dependências adicionais.

## 🔧 Personalização

Para adaptar o projeto a uma fotógrafa real, recomenda-se:

- Substituir as fotografias demonstrativas por imagens autorais.
- Atualizar nome, apresentação e informações de contato.
- Personalizar as categorias da galeria.
- Configurar o número de WhatsApp no arquivo `js/script.js`.
- Atualizar os links das redes sociais.

## 📌 Objetivo do projeto

Este projeto foi desenvolvido com finalidade educacional e de portfólio, buscando praticar conceitos fundamentais do desenvolvimento Front-End, como estruturação de páginas, estilização, manipulação do DOM, eventos JavaScript e responsividade.
